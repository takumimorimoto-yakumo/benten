### Historical quote-only runtime boundary, retained beneath purchase P0

Keep the snapshot facts API and acquisition traffic as separate failure/security domains:

```text
browser -> static Web -> snapshot facts API
        -> quote-only BFF -> independent connectivity owner -> Meteora/RPC
external server/agent ------------------------------^ -> unsigned context
external wallet/signer: revalidate -> sign/send/recover (outside Benten)
```

Recommended Benten paths are future `apps/acquisition-bff/src/index.ts`, `apps/acquisition-bff/src/routes/{session,quotes}.ts`, `apps/acquisition-bff/src/admission/{memory,redis}.ts`, `packages/acquisition-consumer/src/{contract,client,policy,admission-port}.ts`, and `apps/public-web/app/components/domain/acquisition-quote.tsx`. The BFF imports only the Benten consumer contract/client, never a DEX SDK, financial source, signer or private execution module. It keeps no order/quote database. A `POST /api/acquisition/session` accepts no body after exact Origin/Host checks and returns `201`, an opaque `__Host-` HttpOnly/Secure/SameSite=Strict 10-minute cookie plus body-only CSRF/initial nonce/expiry; a `POST /api/acquisition/quotes` requires those exact CSRF and one-time nonce headers, and accepts only `context_version`, exact allowlisted output mint and canonical `input_raw` within the reviewed 1–100 USDC pilot. Body cap is 2 KiB; unknown/repeated fields fail 400. The BFF adds its server-held, audience/scope-bound **consumer access token** to the owner call and never returns it.

Production abuse state uses the dedicated shared TTL admission model frozen in the [unsigned contract](unsigned-acquisition-tool-contract.md) §4; that section alone defines Redis key families, TTL/capacity/quota constants, nonce/lease CAS and rotation acceptance. Every routine or emergency rotation immediately rejects prior-epoch sessions; there is no validation overlap. This plan does not restate a second algorithm. The in-memory adapter is test-only; multi-instance release still requires script-hash/restart/race/rotation/capacity evidence. Session/token expiry is 401, CSRF/policy/replay 403/409, quota 429, route change/quote expiry 409, upstream timeout 504 and typed store/owner unavailable 503; all responses are `Cache-Control: no-store` and redact address/token/provider payloads.

The existing quote route still returns only an owner-independent `indicative_quote`: exact route/policy revisions, source slot/time/age, raw input/gross/net/minimum output, `FeeComponent[]`, quote expiry and `not_authorization`. It cannot satisfy purchase P0. The distinct purchase operation and browser execution are governed only by [User-authorized browser execution v1](contracts/user-authorized-browser-execution-v1.md); unknown required economics, owner/ATA/hook state or transaction audit emits no bytes. If purchase isolation cannot be proved, Buy is unavailable while facts and quote evidence stay independently truthful.
