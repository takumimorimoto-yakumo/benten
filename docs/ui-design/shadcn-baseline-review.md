## W2a observed CLI output (2026-09-24)

`shadcn@4.21.0` ran `init --no-monorepo -b base -p nova` and `add button card table badge separator alert` in `apps/public-web`. The CLI result matches the F0 preflight: `components.json` style `base-nova`, **Base UI** primitives (`@base-ui/react`), `neutral` base color with CSS variables, and **Lucide** icons. The Nova preset additionally generated, and the app keeps unchanged, the Geist variable font (`@fontsource-variable/geist`, set as `--font-sans`), `tw-animate-css`, `shadcn/tailwind.css`, and a `cn` helper imported from the `cn` package (`app/lib/utils.ts` re-exports it). These are generated defaults, not bespoke additions. The CLI's caret ranges were pinned to the installed exact versions. Generated tokens in `app/static.css` are untouched; Benten-specific layout values live in a separate, named token block in the same file.

Intentional deviation (2026-09-24, W2b QA NG-2): the generated focus ring (`--ring` at 50%, about `#d0d0d0`, 1.54:1 on the card) fails the 3:1 non-text contrast for a focus indicator, so `app/static.css` gives every control an opaque 3px outline in the generated neutral-500 value (`--muted-foreground`, about 4.7:1) with a 2px offset; the generated `--ring` token itself is left unchanged.

W3 chart (2026-09-24): `shadcn@4.21.0 add chart` generated `app/components/ui/chart.tsx` unchanged and added `recharts` (pinned `3.8.0`). Series colours are the generated `--chart-*` tokens and `--foreground`; no custom palette. The chart component and Recharts are imported only by the dynamic chart island (`app/features/chart-island`), never by a static page graph.

## Light and dark themes (2026-09-25)

User instruction (2026-09-25): implement light and dark mode. The choices are System (default), Light and Dark, in a header menu next to the language menu.

- **Mechanism.** A small inline script (`app/features/theme/theme-boot.ts`, serialized into every prerendered `<head>` before the stylesheet) reads `localStorage["benten:theme"]` (missing, unknown or unreadable means System), sets or removes shadcn's `.dark` class on `<html>`, sets `color-scheme` and `data-theme-choice`, and stays installed: System follows `prefers-color-scheme` live, a choice made in the menu's radios is stored (and still applied when storage is blocked), and a choice made in another tab is followed. It needs no React, so the menu also works in the not-found documents that do not hydrate. Only `<html>` carries `suppressHydrationWarning`. `<meta name="color-scheme" content="light dark">` keeps the browser canvas right until the stylesheet applies.
- **No JavaScript.** The `dark` custom variant in `app/static.css` matches `.dark`, or `prefers-color-scheme: dark` while `<html>` has no `data-theme-choice` (no script ran). The generated `.dark` block is written once inside `:root { @variant dark { ... } }`, so Tailwind emits it for both selectors; the values are the generated ones, unchanged.
- **Tokens.** Benten's own colour tokens have dark values in one block at the end of `static.css` (`--verified`, `--verified-surface`, `--disabled-ink`, the chart roles `--chart-price`, `--chart-revenue`, `--chart-revenue-edge`, `--chart-net-income`, `--chart-before-listing`, `--chart-seam`, the statements' chart roles `--chart-statement-quiet`, `--chart-statement-quiet-edge`, `--chart-statement-middle`, `--chart-statement-strong`, and `--scrim`); the rest are `var()` or `color-mix()` of generated tokens and follow them. In dark the chart keeps its encoding (revenue a quiet fill with a strong edge, net income a strong solid) with the generated neutral chart tokens. `tests/theme.test.ts` checks that every colour token resolves in dark and computes the main contrast pairs in both themes.
- **Intentional deviation.** The generated light `--muted-foreground` (`oklch(0.556 0 0)`) is 4.34:1 on `--muted`, where secondary text sits (chart readout and empty states), so the theme block sets it to `oklch(0.54 0 0)` (4.62:1 there, 5.04:1 on the page). The dark value stays generated.
- **Browser UI colour.** Two `theme-color` metas with `media` (`#ffffff`, `#0a0a0a`); a pinned Light or Dark adds a third, first in the head, in that theme's colour. The prerendered pair is never rewritten, so hydration matches it.
- **Header.** Below `md` the header shows icons only: back (detail pages), the mark (the name `Benten` is in the link's `aria-label`), language, theme and wallet (a dot marks a connected wallet). Its controls are `--app-header-control-size` (`max(44px, 1rem + 20px)`), so at 200% text the whole row still fits 390px. The tab bar is rendered after the page below `md`, so focus order matches what is seen.

Financial statements (2026-09-25): `shadcn@4.21.0 add tabs` generated `app/components/ui/tabs.tsx` (Base UI Tabs) unchanged. The statements section overrides only layout on it (a wrapping `line` list and touch-size triggers) and renders it after hydration, so a prerendered company page keeps no button. The statements' small charts share the chart island and its one dynamic import (`app/features/charts/load-chart-island.ts`).
